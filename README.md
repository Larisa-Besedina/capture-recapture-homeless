## Оценка численности населения методом повторного охвата (capture-recapture)

Репозиторий содержит код, использованный для подготовки статьи "Оценка численности населения в состоянии бездомности методом повторного охвата: на примере города Санкт-Петербург".


## Структура репозитория

```
├── config.py                  единая точка настройки: пути, переменные, seed, пороги
├── requirements.txt
├── data/
│   ├── raw/                   исходные таблицы сопряжённости (не изменяются кодом)
│   ├── interim/               промежуточные результаты: метрики, оценки по методам
│   └── result/                final_estimates.csv и .xlsx — итоговые оценки
├── pictures/                  все графики (создаются кодом)
├── notebooks/
│   └── analysis.ipynb       сценарий анализа с комментариями
└── src/
    ├── data_io.py             чтение, валидация, сохранение (csv и xlsx)
    ├── formatting.py          округление таблиц для показа и сохранения
    ├── descriptives.py        описательные метрики по стратам
    ├── loglinear.py           генерация, подгонка и отбор лог-линейных моделей
    ├── bootstrap_loglin.py    параметрический бутстреп
    ├── chao_zelterman.py      оценки Чао и Зельтермана + непараметрический бутстреп
    ├── triangulation.py       правило сведения трёх оценок к одной
    ├── plots.py               графики
    └── pipeline.py            сборка анализа по всем сезонам
```
